# Transfer lampiran vendor dan unduhan ZIP

Unggahan dari UI mengirim `background=1`. Server memeriksa format dan checksum, menyimpan salinan sementara privat, kemudian menjawab HTTP 202. Status **diterima** berbeda dengan **siap di OneDrive**. Pengguna boleh menutup dialog atau berpindah halaman. Dokumen baru dapat dicari/diunduh setelah transfer dan verifikasi SHA-256 cloud berhasil. Permintaan API tanpa flag tetap mendukung alur sinkron sebelumnya.

Antrean tersimpan di database, bukan memori PHP. `vendor:transfers` memakai satu lock global dan lock setiap dokumen. Worker CLI langsung dibangunkan melalui proses terpisah; scheduler setiap menit memulihkan peluncuran yang tertunda. Setiap worker memulai paling banyak 12 pekerjaan selama jendela 240 detik, tanpa memotong transfer yang sedang berjalan. Transfer memiliki timeout 300 detik. Percobaan ulang memakai cloud path dan checksum yang sama, paling banyak tiga kali dengan jeda; status tidak pernah menjadi siap hanya karena HTTP unggah sudah diterima. Antrean yang gagal dapat dilanjutkan dengan berkas asli yang sama.

Salinan antrean maksimal 128 MiB dan kedaluwarsa setelah 24 jam. Ruang kosong minimal 100 MiB dipertahankan sebelum menerima antrean baru. Berkas sementara milik transfer dihapus setelah berhasil, gagal, atau pembersihan terjadwal. Salinan antrean yang gagal tidak dianggap arsip permanen; pengguna perlu mencoba ulang jika sudah kedaluwarsa.

Jalur unggah ke folder bulanan yang sudah tersedia memakai satu PUT melalui path Graph, tanpa mencari seluruh folder induk setiap kali. Parent yang belum tersedia tetap dibuat melalui adapter yang sudah ada. Byte verifikasi di-stream ke berkas sementara, bukan menampung semua isi di memori.

**Unduh cepat** untuk dokumen dengan eTag terverifikasi melakukan otorisasi aplikasi, memeriksa ukuran/eTag di OneDrive, lalu mengarahkan browser ke URL HTTPS sementara dari Microsoft. Token OAuth tidak dikirim ke browser. URL tersebut merupakan kapabilitas unduhan sementara; penerimanya dapat mengunduh selama URL masih berlaku, sehingga tidak boleh dibagikan. Resolver hanya menyimpan URL secara privat selama 30 detik dan respons memakai no-store/no-referrer. Perubahan eTag ditolak sampai integritas berkas diperiksa kembali. Berkas lama tanpa eTag memakai unduhan SHA-256 terverifikasi terlebih dahulu; eTag kemudian disimpan untuk jalur cepat berikutnya. Nama file dalam unduhan langsung mengikuti nama objek OneDrive; ZIP mempertahankan nama dokumen yang ramah pengguna.

Pembacaan ulang dokumen di aplikasi tetap memakai endpoint proxy yang kompatibel. Cache baca privat maksimal 64 MiB/15 menit mempercepat pembuatan ZIP dan berkas lama, dengan checksum diverifikasi sebelum pemakaian. Cache bukan lokasi arsip asli dan selalu diotorisasi ulang melalui vendor/dokumen. Cache dibersihkan saat penghapusan dokumen atau kedaluwarsa.

**Unduh semua · ZIP** membuat snapshot seluruh lampiran berstatus siap pada vendor tersebut, terpisah dari filter daftar. Berkas yang masih antre/belum siap tidak disertakan dan UI menjelaskannya. Satu ZIP maksimal 200 berkas/100 MiB; melewati batas ditolak dengan penjelasan, tidak dipotong diam-diam. Proses berjalan di worker, menampilkan progres, dan hanya menghasilkan paket lengkap. PDF/Office/gambar yang sudah terkompresi disimpan tanpa kompresi ulang untuk menghemat CPU. Nama ZIP mencegah traversal dan benturan nama dengan nomor urut. Perubahan/hapus/tambahan lampiran siap membatalkan snapshot lama saat unduh.

Paket hanya dapat dilihat/diunduh oleh pemilik permintaan yang tetap berhak mengakses vendor. Viewer dapat menyiapkan ekspor baca ini, tetapi tetap tidak dapat mengunggah/mengubah dokumen. Paket yang sama digunakan kembali sampai satu jam. Maksimal delapan paket mengantre dan 200 MiB ZIP/berkas kerja; ruang disk dan waktu proses dibatasi. Paket kedaluwarsa dibersihkan. Status tidak menampilkan cloud path, token, checksum, atau teks dokumen. Polling berhenti saat dialog ditutup dan hanya berjalan saat diperlukan, dengan batas sepuluh menit.

Perubahan ini mempercepat alur vendor dan mengurangi pekerjaan hosting per transfer. Kecepatan jaringan pengguna, hosting, serta OneDrive tetap memengaruhi waktu penyelesaian; bukan klaim seluruh website bebas lag.

Pengujian: `VendorTransferPerformanceTest`, regresi `VendorDocumentsTest`, dan browser `vendor-transfers.cjs` desktop/ponsel. Referensi API: [Microsoft Graph download content](https://learn.microsoft.com/en-us/graph/api/driveitem-get-content?view=graph-rest-1.0), [upload small files](https://learn.microsoft.com/en-us/graph/api/driveitem-put-content?view=graph-rest-1.0).
